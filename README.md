# Менің күнделігім — компьютерге арналған қолданба (Electron)

## Бір рет жасалатын дайындық
1. https://nodejs.org сайтынан **LTS** нұсқасын жүктеп орнат.
2. Осы папканы (`kundelik-app`) ашып, мекенжай жолына `cmd` деп жазып Enter бас (немесе папкада PowerShell/Терминал аш).
3. Мына команданы орында (интернет керек):

       npm install --save-dev electron electron-builder

## Іске қосып көру
       npm start

Күнделік жеке терезеде ашылады. Бәрі дұрыс болса, келесі қадамға өт.

## Орнатқыш (.exe) жасау
       npm run build

Нәтиже `dist` папкасында шығады: **Kundelik Setup 1.0.0.exe**. Соны екі рет басып орнатасың,
содан кейін Пуск мәзірінде және жұмыс үстелінде «Менің күнделігім» белгісі пайда болады.

### Мүмкін қиындықтар
- **Windows: "Cannot create symbolic link" қатесі.** Терминалды «Әкімші ретінде» аш,
  немесе Параметрлер → Жүйе → Әзірлеушілерге арналған → *Developer Mode* қос. Содан кейін қайта жаса.
- **Орнату кезінде "Windows қорғады" (SmartScreen) шықса:** «Қосымша ақпарат» → «Бәрібір орындау».
  Бұл қолданбаға цифрлық қол қойылмағандықтан болады, қауіпті дегенді білдірмейді.
- **Mac үшін** `.dmg` тек Mac компьютерінде жасалады (`npm run build` сол жерде).

## Деректер қайда сақталады
- Windows: `%APPDATA%\Kundelik` папкасында (Пуск → Win+R → осыны жаз).
- Қолданбаны өшірсең немесе Windows-ты қайта орнатсаң, бұл папка жоғалуы мүмкін.
  Сондықтан «Бүгін» бетіндегі **Көшірме жасау** батырмасын жиі басып, файлды басқа жерге (флешка, бұлт) сақта.
- `package.json` ішіндегі `name` / `productName` мәнін кейін өзгертпе: деректер папкасының аты өзгеріп,
  жазбалар көрінбей қалады.
